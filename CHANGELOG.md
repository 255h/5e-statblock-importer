# v3.0.0 — JSON-импорт и поддержка русского языка

## Что нового

- Ввод структурированного JSON через редактор или загрузку `.json`-файла.
- Проверка полей с указанием пути ошибки и предварительный просмотр данных.
- Сохранён импорт характеристик, КД, HP, скоростей, чувств, навыков, спасбросков, иммунитетов, снаряжения, источников и биографии.
- Поддерживаются особенности, действия, бонусные действия, реакции, легендарные действия, действия логова, мифические действия и возможности MCDM.
- Явная механика атак, спасбросков, урона, целей, перезарядки, использований и заклинаний.
- Русские имена и описания сохраняются с исходным регистром, `ё`, кавычками и переносами строк. Поиск в компендиумах корректно различает кириллические названия.
- Легендарное сопротивление и общие описания особых действий можно задавать независимо от английских названий.
- Добавлен самодостаточный skill генерации персонажей для ChatGPT в браузере, включая полный контракт JSON и примеры.
- API `parse()` и `import()` принимает JSON-строку или JavaScript-объект.

## Переход с версии 2.x

Окно импорта и API теперь ожидают JSON вместо текста. Для нового импорта используйте примеры `glabrezu.json`, `russian-character.json` и описание формата в README. Уже созданные актёры не требуют преобразования. Дополнение по-прежнему создаёт листы NPC.

## Установка в Foundry

Manifest URL:

```text
https://github.com/255h/5e-statblock-importer/releases/latest/download/module.json
```

Вложения релиза:

- `module.json` — установочный манифест Foundry.
- `5e-statblock-importer-v3.0.0.zip` — архив дополнения.
- `chatgpt-foundry-character-skill.zip` — skill и два JSON-примера для ChatGPT.
- `SKILL.md` — самодостаточная инструкция для загрузки в чат.
- `russian-character.json` — готовый пример русскоязычного NPC.

## Проверки

10 автоматических тестов на имитации API Foundry, валидация JSON-примеров и проверка синтаксиса JavaScript. Проверка интерфейса в запущенной Foundry VTT отдельно не выполнялась.
